# Smart Inverter App v3.0.2

## Equipment status (energy flow)
- **Tap any node** (Solar, AC input, Battery, Consumption) to see all its real-time readings, with Italian names; tap a reading for its explanation.
- New **Inverter** node in the centre, drawn with the electrical inverter symbol: tap it for losses, temperature, working state, priorities, ratings and firmware.
- Flow direction is clearer: moving arrows along each active path.
- The battery arrow is shown whenever solar and AC input are both 0 (the battery is then the only source), even if its current reads ~0 A.
- The house node now reads **Consumption**.
- Removed the full-screen view of the energy flow.

## Readings
- Solar power under 5 W is shown as 0 (realtime, charts and totals).
- More inverter status texts from the API are translated (e.g. "Panels not connected"); unknown ones are written to the debug log.
