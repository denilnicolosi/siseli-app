# Smart Inverter App v2.0.10

Maintenance release: cleanup and internal refactoring. No new features; app behaviour is unchanged.

## Changes
- **Smaller download**: removed ~5.5 MB of unused images bundled in the app.
- **Updates**: the in-app updater now uses the same network client as the rest of the app.
- **Privacy**: the access token is no longer saved to disk. It was never reused (the app always signs in again with your saved credentials), and older saved copies are deleted when you log out.
- **Logs**: API errors that were only visible to developers now appear in the in-app logs, with sensitive data masked.

## Under the hood
- Removed unused code, screens and translation strings.
- One shared check for day/night tariff hours, covered by tests.
- Dashboard and Settings code split into smaller files.
- Documentation moved to `docs/`.

## Android
The APK is a **debug build** (this repository has no release signing key yet). To install it, allow installation from unknown sources when prompted.
