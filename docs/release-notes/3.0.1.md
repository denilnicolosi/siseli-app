# Smart Inverter App v3.0.1

## Energy history chart
- **Period totals** under the chart for day, week and month: production, consumption, battery charge, battery discharge and AC input.
- Tooltips show the time (**HH:mm**) in the day view and the day in week/month views; they no longer get cut off at the edges.
- Date selector is centred and shows the weekday (Mon, Tue, …).
- Month view is built from the inverter telemetry, so consumption, battery and AC input are no longer 0 (the monthly summary only had solar). Bars no longer overlap and the axis shows every 5th day.
- AC input energy only counts when the AC input has voltage: no more phantom AC energy on off-grid days.

## Dashboard
- **Battery duration forecast** under the battery SOC chart: estimated time and date when the battery runs out.
- Note that data updates automatically every 60 seconds.

## Battery and location
- Battery charge (SOC) now uses the BMS value for lithium batteries with communication, so it matches the SmartESS/Siseli app (it was recomputed from voltage and could read 80% instead of 97%).
- The site position can be detected from the device (GPS) in Settings → Station parameters, with the time zone looked up automatically. Old cached positions are ignored.

## Settings
- Simplified the Settings page (danger zone card and "last checked" update line removed).
