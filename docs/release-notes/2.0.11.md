# Smart Inverter App v2.0.11

Fixes in-app updates on Android.

## ⚠️ Android: reinstall once
Earlier Android builds were signed with a temporary key that changed on every build. Android refused updates with a "package conflicts with an existing package" error.

From this version on, the APK is signed with a permanent release key. To switch over, **uninstall the current app once**, then install this APK. You will need to sign in again and re-enter your settings. Later updates install normally from inside the app.

## Changes
- **Italian is now the default language** for new installs. If you had already chosen a language, it is kept. You can still switch in Settings → Language.

## Fixes
- **Android updates**: if Android blocks installs from the app, it now opens the "Install unknown apps" setting for Smart Inverter. Allow it, return to the app and tap **Install**: the already-downloaded file is used. Previously the app opened the browser and downloaded the update a second time.
- **Android**: the APK is now a signed release build, smaller and faster than the previous debug builds.
