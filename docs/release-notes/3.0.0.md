# Smart Inverter App v3.0.0

Off-grid edition. The app now targets an off-grid solar plant (Easun iSolar SMH III, optional generator on the AC input): it monitors the system and lets you change inverter settings by hand. **It never changes inverter settings on its own.**

## ⚠️ Breaking changes
- **HEMS removed**: Adaptive, Night arbitrage and Storm modes, schedule rules, event history and the **Automation** tab are gone.
- **No background automations**: the app no longer forces USB/SNU on low battery or stale data, and no longer mutes the buzzer at night.
- **No tariffs or bills**: tariff settings, monthly savings/payment and the cost per hour are removed.
- **No grid outage detection**: outage banner, estimated backup runtime and outage notifications are removed. The grid tile is now **AC input** (generator).

## Dashboard
- Compact real-time overview: two columns on phones, smaller text and icons.
- Energy history chart is smaller and has a **full-screen** button that turns the phone to landscape (with a button to rotate back). On desktop it uses native full screen.
- Day view with only **Battery** selected shows the battery charge (SOC %) during the day.
- Energy flow: the Δ chip is now **Losses** (inverter self-consumption and conversion), with an explanation on tap. Unexplained solar power is no longer shown as "solar → grid".
- The bottom navigation bar no longer covers the end of the page.
- Removed: diagnostics snapshot, hourly-telemetry stats, second equipment card, monthly breakdown, SOC history card.

## Solar forecast
- Uses the **site latitude/longitude** from Settings → Station parameters (it was always computed for Lviv, Ukraine). Set your location there.
- Sized on your panel power (default 3 kWp). Samples taken with the battery at 95% or more are ignored when learning, because the charger limits solar power when the battery is full.

## Inverter settings and readings (Data tab)
- Every setting and every real-time reading has an **Italian name and an explanation** based on the Easun iSolar manual (LCD program numbers included). Readings have an ⓘ button.
- Values show the option name ("LiFe", "OSO - Solar only") instead of raw numbers, and API states are translated.
- Fixed: inverter settings sometimes stayed on "Loading settings…" after they had been received.

## Docs
- `DEBUG_LOGGING.md` is now in English and Ukrainian; HEMS documentation removed.
