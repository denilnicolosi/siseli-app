# Smart Inverter App v3.0.4

## Equipment status
- **Battery power is easier to read.** The battery node shows the charge level on the first line and the power below it, with a sign: `+` charging, `−` discharging. Three-digit values are no longer cut off.

## Energy history
- The "Energy Overview" section is now called **Energy history**.
- The Day / Week / Month selector spans the full width with equal buttons ("Week" no longer wraps on small phones); the date bar below has the same height and shows the full weekday.
- New **Today** button next to the date to jump back to the current day, week or month.
- The section's own refresh button is gone: the main refresh (button, pull-to-refresh, Ctrl+R) now reloads the history and the forecast too.
- Chart axes show units (W, kW, Wh, kWh).
- The AC input chip and total are hidden when the period has no AC input.
- Removed the "'+' means charge" hint below the totals.

## Solar forecast
- Moved to its own card: **Solar forecast for the next days**, with full weekday names.
- **More consistent estimate.** Physical model for flat panels: Open-Meteo radiation × panel power × 80% system efficiency, never above the panel power. The hourly curve is now centred on the hour each value covers (it was one hour late).
- Removed the correction learned from past PV readings (it was skewed by instant samples, a one-hour offset and off-grid PV throttling) and the unreliable daily **peak**.
